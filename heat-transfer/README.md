# 传热学 · 99题互动抽认卡

面向中文用户的传热学考研复习网页。**纯静态 HTML**，无需账号或后端，适合手机与电脑使用。

## 功能

- 99道题，按7个章节归类，另设“近期新增”（30题）和“全部章节”
- 名词解释与简答题筛选
- 五种抽题模式：等概率不重复、按掌握程度加权、只抽不会、只抽模糊、只抽掌握
- 3D卡片翻转、上一题、答案与评级记录
- 全题库总览、搜索、展开答案和直接修改评级
- 浏览器本地保存；JSON 导入、导出及旧版同域记录迁移
- 响应式布局、系统深浅色适配、减少动画偏好支持

## 使用方式

打开 [index.html](./index.html)。

本项目位于 `world-heritage-map` 仓库的独立 `heat-transfer/` 子目录，不会改动仓库首页的古迹地图。

如需通过 **GitHub Pages** 公开访问，仓库所有者需要在 **Settings → Pages** 中启用从 `main` 分支、`/(root)` 目录部署。完成部署后，预期访问路径为：

`https://fervpluvideus.github.io/world-heritage-map/heat-transfer/`

该地址仅为基于 GitHub Pages 规则的预期路径；启用前不能视为已上线。

## 学习记录与隐私

评级保存在访问网站的浏览器 `localStorage`（标识：`heat-transfer-flashcards-v3`）。源代码和题库可以公开，但用户的学习记录**不会随代码提交上传 GitHub**。

不同域名、浏览器或设备之间不会自动共享本地记录。请在旧版中先导出 JSON，再到新网址的“学习记录”页面导入。导入提供合并与覆盖选项。

## 内容说明

题目和答案基于用户整理、审定的学习笔记；本仓库不包含原始商业辅导资料或扫描教材。
